# H-08 mounted financial UX traceability

**Scope and evidence (2026-10-15 Manila):** Mounted Cashier Dashboard, Transaction History, Shift Settlement and Manager Dashboard, Reports, Orders. The route mounts are in `src/modules/cashier/index.tsx` and `src/modules/manager/index.tsx`. This matrix extends the H-07 financial mapping and metric matrix. The older Cashier “Sales Today” card is not mounted. Terms in the owner policy decision sheet remain unapproved. All time ranges below use Asia/Manila where a calendar date applies; a shift is selected by shift ID and can span dates.

| Mounted figure | Authority, inclusion and time axis | Relation and display meaning |
| --- | --- | --- |
| Cashier Dashboard expected drawer (`CompactShiftHeader`) | `getCashierShiftSummary` calls `calculateShiftTotals` for the recovered **open** shift. Opening cash plus currently completed cash transaction amounts, less client `Refunded` cash rows. No calendar filter. | `cashier_shifts.id` → `cashier_transactions.shift_id` → `payments`. Current drawer estimate, not Manager fulfilled revenue. The current database transaction enum has completed/voided; `Refunded` is only a client model branch. |
| Dashboard recent printable amount | `RecentReceiptsDialog` lists current `Completed` cashier transactions and their `amount`; its date is receipt `created_at`, displayed in Manila. | The transaction links order, payment and shift. A paid unfulfilled order can appear. It is an individual receipt amount, not an aggregate. |
| Transaction History Revenue, Cash, GCash, Average Order | `calculateTransactionSummary` sums only current `Completed` rows among the visible filters. Cash/GCash split by transaction method. Date filters apply to `cashier_transactions.created_at` in Manila. | Hydrated `cashier_transactions` and linked `payments`; the method amount is from the linked payment. **Reconciliation invariant:** H-07's ₱1,020 current verified collections and ₱880 fulfilled sales differ by ₱140 from a paid unfulfilled order. They are different metrics and must not be forced equal. The H-08 retained browser fixture has two paid, unfulfilled receipts totaling ₱30 and therefore ₱0 Manager fulfilled sales.

**Authority limits:** Cashier history currently hydrates the open shift's sales; its closed-shift audit view survives through local client persistence rather than a dedicated closed-shift read. H-08 did not add a query, privilege, RPC, schema field, migration, or accounting rule. Hosted Supabase was not contacted for this phase.
