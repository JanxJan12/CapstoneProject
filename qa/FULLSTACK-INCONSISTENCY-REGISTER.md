- `payments` and `cashier_transactions`, current order status and history, aggregate/batch/ledger stock, formal and Phase 7B request families, Receiving draft and posted stock, sold-time menu snapshots, KDS credential and queue, and assignment/proof bytes are distinct business grains. Their presence alone is not redundancy. Their exact cross-record invariants and conditional empty hosted branches are in the [relationship assessment](DATABASE-RELATIONSHIP-INTEGRITY-ASSESSMENT.md).
- Manager `PurchaseOrdersPage.tsx` reads `prototypePurchaseOrders` but is absent from current navigation. Supplier/PO database objects remain valid for direct-supplier Receiving. This is **UI-only disconnected code**, not a reason to delete tables.
- `src/modules/rider/screens/*` contains older web screens disconnected from the active `RiderApp` in `src/modules/rider/index.tsx`. The standalone Android `App.tsx` is a separate active application.
- Inventory Audit explicitly marks limited history as insufficient and says it does not verify physical stock. This is an intentionally bounded read model, not a confirmed balance defect.
