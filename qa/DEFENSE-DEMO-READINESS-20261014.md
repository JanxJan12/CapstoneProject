# RRJ’s Food-House defense demonstration readiness — 14 October 2026

## Decision

**GO for a rehearsed, isolated, synthetic-data defense demonstration on the local laptop.** The prepared web and database workflow is usable; presenters must use the private local role card and newly generated order/request numbers. This GO applies only to the named local demo environment and the tested actions below. **Actual restaurant deployment remains NO-GO.** The unmodified historical 51-migration replay still stops at Phase 2A (`SQLSTATE 23503`); authoritative master menu, stock, and confidential recipes were never comprehensively supplied; hosted recovery and release gates remain open. The hosted Supabase project was read-only throughout this phase.

The demo fixture contains fictional sample quantities and a sample `Extra rice` option. Any item name coinciding with an interview-confirmed example is still a **demo record** here; its price, stock, recipe, and completeness are not asserted as authoritative. GCash proof upload and Cashier verification represent an internal payment decision, not external settlement.
